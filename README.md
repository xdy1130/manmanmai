# 慢慢买

这是从“杂七杂八”项目同步过来的“慢慢买”直播购物冷静助手。当前目录已包含网页主程序、离线缓存、PWA 配置、Supabase 数据库脚本和项目配置说明。

## 快速运行

在当前目录启动一个静态文件服务，然后访问 `http://127.0.0.1:8087/`。直接双击 `index.html` 也能查看本地界面，但登录、云端同步和 Service Worker 需要通过 HTTP 服务访问。

## 重要文件

- `index.html`：网页主程序
- `项目配置说明.md`：正式网址、Supabase 项目、账号与同步说明
- `supabase-schema.sql`：`app_state` 表及 RLS 策略
- `manifest.json`、`app-icon.svg`、`sw.js`：PWA 与离线缓存配置

## 已同步的产品信息

- 默认月预算：¥2000；主播规则默认每场¥500、“喜欢就买”额度¥200；库存预警上限为6个月。
- 主要模块：购买决策、库存、消费/退款账单与趋势、自然语言快速记账、导入导出、账号云同步。
- 数据核心字段：`inventory`（库存）、`expenses`（消费和退款）、`hosts`（主播规则）、`chatHistory`（记账对话）。退款以负金额记录。
- 云端表为 `app_state`，按账号 `user_id` 通过 RLS 隔离；本地数据保存在浏览器 `localStorage` 中。

## 常见报错排查

1. 页面空白：确认通过 HTTP 服务访问，并打开浏览器开发者控制台查看首个报错。
2. 登录或同步失败：检查网络、Supabase URL/Publishable key，以及数据库是否已执行 `supabase-schema.sql`。
3. 离线缓存异常：清除本站点缓存后重新加载；修改 `sw.js` 中的缓存版本号可强制刷新缓存。

源项目里曾有一个“记录昨天的消费和退货”任务，它的失败记录来自上游模型接口的 401/API key 问题；这与本网页的前端和 Supabase 数据表无关。遇到类似提示时，应先检查调用该外部接口的任务配置，而不是反复修改本项目页面。
